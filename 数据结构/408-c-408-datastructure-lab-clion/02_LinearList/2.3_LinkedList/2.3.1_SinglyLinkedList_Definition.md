# 2.3.1 单链表的定义

对应代码：[2.3.1_SinglyLinkedList_Definition.cpp](./2.3.1_SinglyLinkedList_Definition.cpp)。当前已实现无头结点的三结点链与遍历。未提供王道正文，教材版本中的例外和具体表述待核对。

## 1. 核心概念

- 单链表是线性表的链式存储：每个结点含数据域和指针域，指针域保存直接后继结点的地址。逻辑上相邻的元素，物理位置不要求相邻。
- 普通单链表的末结点 `next` 为 `nullptr`；沿后继指针可依次访问结点，不能直接按下标随机存取。
- 头指针指向链表的第一个结点；带头结点时指向头结点，不带时指向首元结点。头结点是首元结点之前的附加结点，不计入表长，数据域通常不存放元素，也可存放表长等附加信息。

## 2. 必会代码 / 操作

| 当前代码 | 概念对应 |
|---|---|
| `struct LNode { int data; LNode *next; };` | 数据域存元素，指针域存后继地址；`LNode` 是结点类型 |
| `a.next = &b; b.next = &c;` | 用地址建立逻辑次序，与变量的物理排列无关 |
| `c.next = nullptr;` | 标记普通单链表结束 |
| `LNode *p = &a;` | `p` 最初指向首元结点；此例没有头结点 |
| `p = p->next;` | 沿后继链移动遍历指针，不移动结点 |

当前访问顺序为 `10 → 20 → 30`。循环先判断 `p != nullptr`，再访问 `p->data`。

教材常见的 `typedef struct LNode { ... } LNode, *LinkList;` 中，`LinkList` 是结点指针类型的别名；`LNode *` 和 `LinkList` 类型相同，命名分别强调“结点指针”和“链表”。当前代码使用前者，不必为命名改答案。

## 3. 边界条件

- 不带头结点：空表为 `L == nullptr`；非空表的 `L` 指向首元结点。
- 带头结点：已成功初始化的空表仍有头结点，`L != nullptr` 且 `L->next == nullptr`。`L == nullptr` 不能视为这种表示下的正常空表。
- 单个元素：不带头结点时首元结点也是尾结点；带头结点时有头结点和一个数据结点。两者尾结点的 `next` 均为空。
- 空指针不能解引用；判断 `L->next` 前必须保证 `L` 指向有效结点。
- 局部结点的未初始化指针不能当作有效链接。当前代码在遍历前给三个 `next` 都赋了值，且遍历发生在 `a、b、c` 的有效生存期内。

## 4. 易混概念辨析

- **头指针 ≠ 头结点 ≠ 首元结点**：指针是地址变量，头结点是可选附加结点，首元结点存第一个元素。无论是否带头结点，访问链表都需要入口指针。
- **逻辑结构 ≠ 存储结构**：单链表所表示的线性表仍是线性结构；“链式”描述存储方式。
- **结点 ≠ 元素**：结点还含指针域；带头结点时，结点总数是元素数加一。
- 当前 `a` 存储元素 `10`，是首元结点，不是因为位于链首就成为“头结点”。

## 5. 选择题细节

- 链式存储不要求整张表占用连续空间，但不等于结点必然不相邻；逻辑关系由指针表示。
- 单链表属于顺序存取结构。已知头指针后，按位找到第 `i` 个元素通常需沿链访问，耗时 O(i)，最坏 O(n)；按值查找最坏 O(n)。此处只记结论，实现留到 2.3.2。
- 已知某结点的有效指针时，读取其数据或后继指针为 O(1)；这不意味着能按序号 O(1) 定位结点。
- n 个元素的链表存储空间为 O(n)，每个结点有指针域开销；带头结点额外增加一个结点。当前遍历耗时 O(n)，辅助空间 O(1)，不含链表本身。
- 带头结点可统一首位置操作与其他位置操作、空表与非空表的处理；它不会使链表获得随机存取能力。
- 普通单链表通过空指针结束；“所有链表末结点指针都为空”不成立，循环链表另有约定，留到对应小节。
- 链式存储不等于必须使用动态分配；当前局部变量结点也能用指针组成链表。不能据此返回已失效局部结点的地址。

## 7. 我的错误

以下错误来自教学对话《代码学数据结构》，当前 cpp 中均已改正，保留用于复习。

### 1. 遍历条件误写为 `p->next != nullptr`

- **错误原因**：判断的是“当前结点是否有后继”。走到尾结点时，`p->next == nullptr`，循环提前结束，尾结点未被访问。单元素链表会一个元素也不访问；空表还会因解引用空指针而出错。
- **正确思路**：普通单链表的遍历应判断当前结点是否存在，再访问它。

```cpp
while (p != nullptr)
```

### 2. 遍历时忘记移动工作指针

- **错误原因**：非空链表中，若循环内不更新 `p`，它会一直指向同一个结点，反复输出该元素并形成死循环。
- **正确思路**：处理完当前结点后，沿后继指针向后移动。

```cpp
p = p->next;
```

复习提醒：**判断当前结点是否存在 → 处理当前结点 → 移向后继。**

## 8. 一句话复习

单链表靠后继指针连接元素；先分清有没有头结点，再判断首元位置、空表条件和遍历起点。
