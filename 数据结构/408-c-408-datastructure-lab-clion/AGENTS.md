# 408 数据结构笔记规则

- Codex 仅维护项目笔记和进度；用户未要求时，不主动教学、布置练习或要求用户贴代码。

- 仅生成、更新用户当前学习的王道小节；不一次生成整本详细笔记，不提前展开后续算法。
- 每个王道小节使用一个按章节编号命名的 `.cpp` 和一个同目录、同名的 `.md`，例如 `2.3.1_SinglyLinkedList_Definition.cpp` / `.md`。
- 现有拆分练习和旧目录保留；未经用户明确授权，不改写、合并、移动或重命名 cpp 答案。进入已有拆分练习的小节时，先确定小节主 cpp 的对应关系，不能为凑配对复制答案或新增可执行入口。
- 不使用 STL 替代王道教材的数据结构实现。笔记围绕王道概念、代码对应关系、408 考点和易错点，不写成软件工程文档。
- md 固定使用以下八个二级标题：核心概念、必会代码 / 操作、边界条件、易混概念辨析、选择题细节、大题 / 算法题考法、我的错误、一句话复习；依次编号 1 至 8。
- 首轮简洁，但王道正文的可考知识点不能因偏僻而省略。定义限定、特殊情况、边界、易混概念、时间/空间复杂度和教材例外，分别在边界条件及选择题细节中明确记录。
- 当前代码未涉及的本节定义和考点可简要说明；后续小节算法不提前大量展开。
- 未提供教材正文时，不声称已逐项覆盖指定版本；记录待核对范围，收到正文后补入当前小节。
- “我的错误”只记录从用户代码、回答或错题中确认的错误；待完成项、常见易错点不冒充用户错误。
- README.md 维护当前小节和学习进度。创建文件、存在 TODO 或仅写完演示代码均不代表已学完；用户确认完成后再勾选。
- 后续每次更新先阅读对应 cpp 和 md，再按新增学习内容更新笔记及进度；除非用户授权修改答案，否则仅在 md 提供问题说明和修改建议。
