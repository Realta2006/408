# 408-DataStructure-Lab

本项目用于考研 408《数据结构》逐章学习和复习，适合在 CLion 中使用 CMake 与 C++17。目录按线性表、栈和队列、串、树、图、查找、排序和复习组织。

每个 `.cpp` 文件都是独立的练习入口，部分文件仍为 TODO，部分已有学习代码。请根据教材和自己的理解补全代码，不依赖第三方库，也不使用单元测试框架。

各练习文件已补齐中文注释、常用头文件及对应的基础类型或结构体定义。2.3.2 的七个练习共用同目录的 `LinkedList.h`，其他章节仍保留各自骨架。基础定义齐备不表示算法已实现或章节已学完。未能从历史对话确认原文的骨架按现有主题补齐；容量、下标、头结点等约定见各文件注释，实际练习以教材和题目要求为准。

- “我的错误”只记录已确认的个人错误；新代码、错题或正文带来新内容时更新对应部分。

## 在 CLion 中使用

1. 用 CLion 打开本目录，等待 CMake 自动加载。
2. 在运行配置中选择所需的学习目标，点击运行或调试。
3. 每个源文件独立编译为一个可执行程序，目标名由相对路径生成。例如 `01_LinearList/01_SeqList/basic.cpp` 对应 `ds_01_LinearList_01_SeqList_basic`。
4. 新增 `.cpp` 文件后，CMake 会在重新加载时发现它，并生成对应目标。
